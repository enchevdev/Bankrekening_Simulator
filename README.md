# Bank Account Simulator

A simple C# console application that simulates basic bank account operations.

## Features

* Enter a name and starting balance
* View the current balance
* Deposit money
* Withdraw money
* Prevent invalid or negative transaction amounts
* Prevent withdrawals when there is insufficient balance
* Validate numeric user input
* Exit the application through the menu

## Technologies

* C#
* .NET
* Visual Studio
* Git & GitHub

## How to Run

1. Clone or download the repository.
2. Open the solution in Visual Studio.
3. Build the project.
4. Run the application.
5. Follow the instructions in the console.
